# 🍰 Cake Shop Website

A modern, responsive, and user-friendly **Cake Shop Website** designed to showcase cakes and bakery products through a clean and attractive web interface.

This project was developed as a frontend web development project using **HTML, CSS, and JavaScript**, with a focus on responsive design, attractive UI, and a smooth browsing experience.

## ✨ Features

* 🏠 Modern Home Page
* 🎂 Cake & Bakery Product Showcase
* 🖼️ Attractive Product Images
* 📱 Responsive Design
* 💻 Desktop & Mobile Friendly
* 🎨 Clean and Modern User Interface
* ⚡ Interactive JavaScript Components
* 📋 Product Information Sections
* 📞 Contact / Customer Information Section
* 🌐 Easy to customize and extend

## 🛠️ Technologies Used

| Technology          | Purpose                            |
| ------------------- | ---------------------------------- |
| **HTML5**           | Website structure                  |
| **CSS3**            | Styling and responsive design      |
| **JavaScript**      | Interactivity and dynamic behavior |
| **Images / Assets** | Product and website visuals        |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/ChaminduKalsara/Cake-Shop-Website.git
```

### 2. Navigate to the Project

```bash
cd Cake-Shop-Website
```

### 3. Run the Website

Open the `index.html` file in your preferred web browser.

For the best development experience, you can use **Visual Studio Code** with the **Live Server** extension.
